# nix

nixos + homemanager + dotfile repository

## Setup

For a new device, update the `nixos/laptop-configuration.nix` file to set the
`boot.initrd.luk.devices."luks-$UUID".device` property.

The contents of this field should already be generated by NixOS in the `nixos/configuration.nix`.
However, the `$UUID` will vary by device so we pop it into an ignored file:

Specifically, the device specific configuration file is ignored via:
```bash
git update-index --assume-unchanged nixos/laptop-configuration.nix
```

## Home Manager Installation

1. Install Nix:

```bash
curl -L https://nixos.org/nix/install | sh
```

2. Clone this repository:

```bash
git clone git@github.com:edfincham/.dotfiles.git
```

3. Initialise home-manager:

```bash
nix run home-manager/master -- init --switch
```

4. Setup dotfile symlinks and build system:

```bash
make init
make hm-rebuild
```

## Daily Usage

If `nix flake update` (or `make update`) is used repeatedly, GitHub may rate limit.
To get around this add the following line to `~/.config/nix/nix.conf`

```bash
access-tokens = github.com=$GH_PAT
```

After making changes run:

```bash
make update
make hm-rebuild
make nixos-rebuild
```

NixOS works by building a new image for each change to the configuration. If a change causes issues, you can always revert to a previous image.

But retaining previous images takes up disk space. It's worth performing a regular clean:

```bash
make clean
```

Run `make help` to see available commands.
