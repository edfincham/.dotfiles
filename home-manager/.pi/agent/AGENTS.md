# Global Instructions for Agents
- When posting a PR to a Slack channel, use slack_send_message_draft to create a draft following the format: :pr: `[+{lines added}, -{lines removed}]` {pr title}{newline}{bare link to PR}
- Git: never add Co-authored-by lines for non-human authors.
- Git: prefix branches with ed/ when adding a new feature
- Plan mode: always write to PLAN.scratch.md when prompted with "plan mode" instead of rendering in the UI.
- Task mode: always write to TASKS.scratch.md when prompted with delegating tasks.
